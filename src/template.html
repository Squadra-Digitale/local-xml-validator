  1. Prüfprofil wählen. Ein Profil enthält die Regeln, nach denen geprüft wird. Wenn Sie eine Profildatei (….xvprofile.json) bekommen haben: einmalig auf „Importieren“ klicken und die Datei auswählen. Danach ist das Profil dauerhaft gespeichert.
  2. XML-Datei hinzufügen. Datei in das gestrichelte Feld ziehen oder auf „Dateien auswählen …“ klicken.
  3. Auf „Prüfen“ klicken. Unten erscheint das Ergebnis: Gültig = alles in Ordnung, Ungültig = es gibt Fehler, die behoben werden müssen. Jeder Fehler wird mit Zeilennummer und Beschreibung aufgelistet.
  1. Choose a validation profile. A profile contains the rules used for validation. If you received a profile file (….xvprofile.json): click “Import” once and select the file. The profile is then stored permanently.
  2. Add an XML file. Drag it into the dashed area or click “Choose files …”.
  3. Click “Validate”. The result appears below: Valid = everything is fine, Invalid = there are errors that need fixing. Each error is listed with line number and description.

    Über dieses Werkzeug & LizenzenAbout this tool & licenses

    Lokale Browser-Umsetzung angelehnt an den ITB XML Validator (Prüfprofile mit XSD und Schematron, Berichte im GITB-TAR-Format). XSD-Prüfung und Wohlgeformtheit: libxml2 (xmllint-wasm, MIT). Schematron: eigene ISO-Schematron-Engine mit XPath 3.1 über SaxonJS; vorkompilierte Schematron-XSLT nur in Version 1.0. Einschränkungen: keine xsl:function/xsl:key in Schematron-Dateien, kein Nachladen externer Ressourcen (document(), Remote-Schemas).

    Local in-browser implementation inspired by the ITB XML Validator (validation profiles with XSD and Schematron, reports in GITB TAR format). XSD and well-formedness: libxml2 (xmllint-wasm, MIT). Schematron: custom ISO Schematron engine with XPath 3.1 via SaxonJS; precompiled Schematron XSLT only in version 1.0. Limitations: no xsl:function/xsl:key in Schematron files, no loading of external resources (document(), remote schemas).
